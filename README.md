# Waynakh Restaurant — сайт (Ницца)

Многоязычный сайт ресторана кавказской кухни: 65 rue de la Buffa, 06000 Nice; тел. 06 14 26 47 03 и 04 83 39 10 48; Instagram @restaurant_waynakh; waynakh.fr.

- Один файл `index.html` (логотип и фото встроены), без сборки, без бронирования
- Языки: FR (по умолчанию), DE, RU, UK, ES, EN — переключатель в шапке; состав блюд переводится автоматически по словарю `ING`
- Дизайн «как Instagram-профиль»: логотип в градиентном кольце, статистика (4,7★ · 705 отзывов · 14,8 k подписчиков), био, круглые «highlights» вместо меню, сетка фото, отзывы в виде комментариев с ♥
- Полное меню (33 позиции): закуски, супы, плат, гриль (халяль), десерты; фильтры по категории и «без мяса»
- ФИШКА: квиз «Какое блюдо Кавказа создано для вас?» — 3 вопроса → персональная рекомендация из меню с вращающейся 3D-тарелкой, кнопки «Показать в меню» и «Поделиться»
- 3D (three.js r128): гриль-доска с бараньими рёбрышками, манты, суп с паром; при наведении на кнопки вылетают 3D-блюда; 3D-появление блоков, «магнитные» кнопки, 3D-наклон карточек и фото
- Часы 10:00–21:30 ежедневно + статус «открыто/закрыто» по времени Парижа; мини-карта (схематичная SVG) + Google Maps
- Мобильная версия: 3D-блок сверху, 2 колонки фото, просмотр фото по нажатию

## Как менять
Меню — массив `MENU` (название, цена, состав, размер/диета/настроение для квиза). Тексты — объект `K` (французский в самом HTML, `data-i`). Часы — в функции `stat()` и таблице.

## Проверить перед запуском
Цены читались с фото (в том числе супы и Medovik) — сверить с актуальной картой; напитки и блюда дня на сайт не вынесены. Права на фото и логотип (взяты из Instagram/Google). Тексты и переводы — носителями языков.
