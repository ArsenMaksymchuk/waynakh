# Публикация

## Vercel (бесплатно)
1. Аккаунт на vercel.com
2. `npm i -g vercel`
3. В папке проекта: `vercel`, затем `vercel --prod`
4. Подключить домен кофейни

## Альтернативы
Netlify (перетащить папку), GitHub Pages, обычный хостинг (загрузить index.html).

## После публикации
- Добавить ссылку на сайт в Google Business Profile и в Instagram
- Проверить часы работы, телефон и цены
- Подключить Google Search Console
